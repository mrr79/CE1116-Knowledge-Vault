## 📚 Idea/Concepto 

La tokenización es el proceso de segmentar un flujo de texto en unidades discretas llamadas tokens (palabras o subpalabras). Cada token se vincula a un ID numérico único mediante un vocabulario predefinido, que actúa como un diccionario de referencia para el modelo.
## 📌 Puntos Claves (Opcional)

- Este mapeo es el puente fundamental: transforma el lenguaje humano en índices que la computadora utiliza para extraer vectores (embeddings).
    
- Estos vectores contienen la información numérica necesaria para que la arquitectura de la red neuronal realice los cálculos de contexto y significado.
