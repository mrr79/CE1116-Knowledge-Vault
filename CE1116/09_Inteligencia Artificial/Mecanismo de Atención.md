## 📚 Idea/Concepto 

El mecanismo de atención permite que el modelo determine qué partes del texto son más importantes al procesar una palabra o token.
## 📌 Puntos Claves (Opcional)
- Para hacerlo, compara los tokens usando vectores llamados Query y Key, y calcula qué tan relacionados están.
    
- Luego aplica softmax para asignar pesos a esos resultados y usar los Values para crear una nueva representación del token que resalta la información más relevante dentro de la secuencia.
